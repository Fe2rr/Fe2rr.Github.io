# NAPL — Native Android Port List

NAPL is a community-driven index for discovering, exploring, and tracking native game ports available on Android.

The project brings together port information, community ratings, and device/SoC compatibility reports to help users research Android game ports.

## Features

- Browse and search native Android game ports.
- Explore categories, platforms, and multi-game apps.
- View community ratings and port information.
- Search Android devices and SoCs for community-submitted compatibility reports.
- Compare reported playability across tested devices.

## Technology

The project uses a combination of:

- JavaScript, HTML, and CSS for the main website.
- React and Vite for the supporting application/tooling.
- Supabase for backend services and data storage.
- Lucide for iconography where used.
